# Non-invasive Head Stabilization Models

This folder contains STEP and STL files for non-invasive head stabilization models. These models are designed to provide support and stability for the head without the need for invasive procedures. The files can be used for 3D printing or other manufacturing processes to create physical models for research, medical applications, or educational purposes. Please see the main paper for details on how these models were generated and their intended use cases.

* EEG Helmet.STL — helmet with Ear rings and silicone straps for EEG electrode placement.
* EEG Helmet-cap.STL — just the helmet model
* fix_net1.STL — Ear ring that provides anchor points for the silicone straps used for EEG placement.
